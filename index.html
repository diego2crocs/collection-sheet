WikiSheet
Collection Sheet pour WikiMasters

Votre collection WikiMasters, rangée dans Google Sheets.

Vous taguez vos cartes sur WikiMasters, l'extension les coche dans votre Sheet. Tout seul, toutes les 10 minutes.

ChromeEdgeOperaBraveFirefox

Ce que l'extension suit

  • Les 34 875 communes de France, rangées par département, avec la progression.
  • Les cartes « Liste des communes de… », une par département.
  • Vos objectifs Wikipédia : une catégorie, une page « Liste de… », votre propre liste d'articles, ou tous les articles d'un même genre.
  • La valeur estimée de vos cartes, d'après les dernières ventes du marché.

Installation

  1. Installez l'extension depuis le lien qu'on vous a partagé : Chrome Web Store pour Chrome, Edge, Opera et Brave, ou le module Firefox.
  2. Connectez votre compte Google, puis cliquez sur « Créer mon Google Sheet ».
  3. Ouvrez votre Collection sur WikiMasters et ajoutez vos suivis depuis l'icône de l'extension.

Vos données

L'extension n'accède qu'aux fichiers Google qu'elle a créés. Vos données vont directement de WikiMasters à votre Google Sheet, sans serveur intermédiaire.
